⚡ Desafio de Engenharia de Dados & Estruturação do Excel (Dia 1)

Sua equipe deve entregar a planilha do Excel organizada obrigatoriamente em 3 Abas Profissionais:

1️⃣ Aba: [1_Base_Tratada]

Sua base 100% limpa e sem erros. Adicione 2 colunas calculadas de Scoring/Segmentação:

  • Coluna de Classificação por Quartil/Percentil (Ex: Prata, Ouro, Platina).
  • Coluna de Matriz de Priorização usando =SE(E(...)).

2️⃣ Aba: [2_Auditoria_DQ]

Mini-painel automático de Qualidade de Dados (Data Quality) com fórmulas:

  • =CONT.SE para checar vazios (deve dar 0).
  • =ÉERROS para checar #N/A (deve dar 0).
  • Contador de duplicadas remanescentes (deve dar 0).

3️⃣ Aba: [3_Dicionario_Dados]

Tabela de Governança de Dados documentando todas as colunas:

  • Nome da Coluna | Tipo de Dado | Regra de Negócio | Limite Válido | Tratamento Aplicado.
  • Exemplo de Lista Suspensa (Validação de Dados) configurada.

🔑 Entendendo o Código de Identificação (ID) na Planilha:

  • O que é o ID? É o código único da linha (ex: `CLI-101`, `PED-2001`, `SKU-105`, `SAC-8001`).
  • ID do Cliente (Caso 1): Representa o cadastro do cliente. Como a mesma pessoa pode ter feito várias compras em dias diferentes, o mesmo `ID_Cliente` aparecerá repetido em várias linhas. Para saber se o cliente cancelou/evadiu (Churn), a equipe precisa olhar para a data de compra mais recente desse cliente!
  • ID de Transação/Pedido/Chamado (Casos 2, 3, 5, 6, 7): Cada linha representa um evento único (um frete, um atendimento ou uma venda). IDs exatamente iguais com todas as informações idênticas são duplicidades de digitação que devem ser excluídas.
  • SKU (Caso 4): É o código do produto em estoque. Cuidado com códigos iguais que possuem espaços invisíveis antes ou depois do texto!
💡 Dica Importante: Vocês atuam como consultores analistas. Não existe regra de cor ou layout para a planilha. Sejam organizados e claros nas análises!
